# Drift Timer

A small, light Windows desktop timer with an always-visible saved note and local Pikachu animations.

## First run

1. Open PowerShell in `D:\timer`.
2. Run `npm install` once.
3. Double-click `run_timer.bat` afterwards, or run `npm start`.

## Controls

- Drag the thin top bar to reposition the timer.
- Select a duration, then use the green button or animation circle to start and pause.
- The small note is saved as you type and returns whenever the app opens.
- The diamond button toggles always-on-top; the `X` closes the app.
